# Sensor Toolbox

Sensor Toolbox is an Android app built with Kotlin and Jetpack Compose that displays live readings from the device's built-in sensors. It provides a simple dashboard for common mobile sensors and a references screen for project-related resources.

## Features

- Live sensor monitoring for:
  - Accelerometer
  - Gyroscope
  - Magnetic field
  - Light sensor
  - Relative humidity
  - Ambient temperature
  - Pressure sensor
- Automatic detection of available sensors on the device
- Clean Material 3 UI
- Navigation between the home screen and reference screen
- Developer banner and reference links

# My Learnings

I worked on this app as part of the coursework for EE526: Wearable and Implantable Sensors by Dr. Kwang Oh. I was able to build on what I had learned in Solid State Sensors and realize how those sensing mechanisms are implemented in smartphones, which we use everyday.

I also understood that app development is a useful skill to have in order to showcase your ideas in a concise manner that is accessible to many people. Overall, this was a good experience to have and add as a self-taught project in my resume.
